Aplikacja Pogodowa:

- Pobieranie aktualnych danych pogodowych poprzez **API** lub **Web Scraping**.
- Możliwość zmiany lokalizacji prognozy (**Mapa** lub **Wpis**)
- Konfiguracja preferencji użytkownika (zapis np. w pliku **JSON**).
- Tworzenie menu na pierwszym uruchomieniu aplikacji, w którym użytkownik będzie mógł dostosować preferencje programu.
- Opcje wyświetlania prognozy (np. Fahrenheit/Celsjusz). (liczba czynników od 2 do 6) wyświetlanie tekstowe +plus piktogramy do czynnika (słoneczko, chmurka, itp.,, do opadów, zjawisk, temperatury, ciśnienia, wiatru, itp.)
- prognoza na kolejny dzień
- Stworzenie interfejsu użytkownika przy użyciu Tkinter lub wxPython

Materiały użyte do stworzenia projektu:

- [Dokumentacja API *Open-Meteo.com*](https://open-meteo.com/en/docs)
- [Dokumentacja *tkinter*](https://docs.python.org/3/library/tkinter.html)
- [Ikony *FlatIcon*](https://www.flaticon.com/) (Słowa kluczowe: weather)

## Aby uruchomić program należy:
- Zainstalować wszystkie potrzebne biblioteki za pomocą polecenia `python3 -m pip install -r requirements.txt`
- Uruchomić plik `main.py` za pomocą polecenia `python3 main.py`

### *W przypadku odpalania projektu bezpośrednio z IDE np. Jetbrains PyCharm należy ustawić odpowiedni interpreter dla projektu i zedytować poprawnie ustawienia uruchamiania/debugowania.*
